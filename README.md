# 67-minecraft

Repository for Minecraft-related builds and launchers.

This repo is managed by the user ulycesperez-commits. The add/version-26.1.1 branch contains a manifest and a small launcher that points to Eaglercraft's playable 1.8.8 build at https://eaglercraft.com/play?version=1.8.8.

Note: No Mojang or Eaglercraft proprietary assets are included in this repository. The launcher opens the Eaglercraft web client in the user's browser.
